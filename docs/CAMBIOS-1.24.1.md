# CazaJefes 1.24.1

- `/ri book <rare> <nivel> [jugador]`: exclusivamente libros con rare y nivel. Los activables mantienen clic derecho y los de equipo se aplican en la mesa.
- `/ri essence <rare> [nivel] [jugador]`: exclusivamente Rare Essence en bola de magma, con el poder y nivel solicitados, incluso Haste/Burst. Las de habilidades activables también funcionan con clic derecho. Conservan descripción y nivel tras actualizar el inventario.
- `/ri esscence` y `/ri esencia` son alias del mismo comando. El comando sin ID conserva la entrega de esencia base.
- Los máximos siguen siendo los de cada rare; Haste VII, Carga IV y Cerrojo V, por ejemplo. No se inventa un único máximo para todas.

Validación: Maven verify. Sin ejecución de Paper.
